# 編集基準

- 一次情報を優先し、出典の内容を実際に確認する。発表日と出来事の日付、事実と予測・意見を区別する。裏付けのない数値、引用、人物の発言を作らない。
- 見出しと概要は本文で裏付けられる内容にする。技術用語は読者に分かるように説明し、重要な制約や不確実性も記載する。
- 公開可能な出典のタイトルと HTTP(S) URL を記事データに記載する。出典が事実を支えているか、人がレビューする。
- 3人は架空の AI 生成コメントである。A は根拠のある辛口批判、B は専門的な解説、C は一般読者の感想とし、個人への中傷や虚偽の体験を避ける。
- 画像は記事の要点を伝え、実在の出来事を誤認させない表現にする。代替テキストには見えている内容を書く。

- 読者が仕組みを理解して応用できるよう、記事内容に適した比較表、手順、図解などを使う。装飾のために増やさず、各要素の意味を本文でも説明する。図や表の内容も出典に照らして確認する。
