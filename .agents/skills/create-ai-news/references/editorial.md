# 編集基準

- ニュース媒体、解説記事、一次情報などから、内容を理解するうえで有用で信頼できる出典を選び、実際に確認する。一次情報に限定したり優先したりする必要はない。発表日と出来事の日付、事実と予測・意見を区別し、裏付けのない数値、引用、人物の発言を作らない。
- 日付や広いテーマのニュースは、その期間の複数の話題を選んでまとめる。選定した各ニュースの内容と日付を確認し、話題ごとに出典を示す。特定の出来事を依頼された場合は、それに合う構成にする。
- 見出しと概要は本文で裏付けられる内容にする。技術用語は読者に分かるように説明し、重要な制約や不確実性も記載する。
- 公開可能な出典のタイトルと HTTP(S) URL を記事データに記載する。出典が事実を支えているか、人がレビューする。
- 3人は架空の AI 生成コメントである。A は皮肉や偏りもある辛口批判、B は個性のある専門解説、C は率直な一般読者の感想とし、言葉遣いや視点の違いを出す。意見は意見として表現し、架空の事実や虚偽の体験を作らない。
- 画像は記事の要点を伝え、実在の出来事を誤認させない表現にする。代替テキストには見えている内容を書く。

- 読者が仕組みを理解して応用できるよう、記事内容に適した比較表、手順、図解などを使う。装飾のために増やさず、各要素の意味を本文でも説明する。図や表の内容も出典に照らして確認する。
