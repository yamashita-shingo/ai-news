# 記事制作ログ

記事ごとに `src/content/articles/<記事slug>/log.md` を作成し、記事と同じ PR に含める。ログは公開リポジトリに保存される。秘密情報、認証情報、内部メモ、非公開情報は記録しない。

## 記録項目

- テーマと記事ファイル・画像ファイルのパス
- 調査日時、実際に確認した出典のタイトルと URL
- 記事、画像、3人のコメントの制作概要
- 出典・画像・コメントの確認内容と未検証事項。実行した検証があればその結果
- 修正時は日付と変更の要点を追記する

記録できない情報は推測で埋めず「未確認」と書く。PR 番号や公開結果は判明している場合だけ記載する。ログは制作履歴であり承認の代わりではない。
